## 证据口径

- “独立迁移”必须同时满足：任务类型为干预或复测、题目被明确标为迁移验证题、作答正确、该次作答前未使用提示。
- 动态分组只描述当前任务需要，不作为固定能力标签。
- 班级雷达只读取该班任务证据；个人自学记录不混入教师班级统计，但生成新题草稿时会用于避免给学生重复旧题。
- 任务截止后仍可补交；页面明确告知，数据库保留迟交标记。
