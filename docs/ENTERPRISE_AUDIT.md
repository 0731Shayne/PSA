# PSA 企业交付验收记录

验收日期为 2026 年 11 月 19 日。以 GitHub 上的 `5cc1ac3` 为基线，检查了本地修复后的应用、干净安装、数据库升级和公开演示。业务验证使用临时数据库和测试账号。

**当前版本可作为企业试部署和验收候选。正式上线取决于目标环境对接、备份恢复和容量验证。**

| 教学与实验 | 教师教学包、学生学习单、分层任务、保存过程中继续编辑、学生版下载和打印入口。实验覆盖参数变动、记录保存、重新打开和对比 |
| 在线答疑 | 题库推荐、问答与引用、作业辅导限制、模型故障降级和取消流式请求。外部模型用模拟响应验证 |
| 课程资料 | 用真实本机 Ollama 验证新建、上传、向量索引、下载原件和班级问答引用。其他教师和学生无法下载教师私有原件。验证 PDF、DOCX、PPTX、XLSX、Markdown、TXT 和 HTML 的文本提取。RAGFlow 通过协议和权限测试 |
| 手写作答 | 模拟 MinerU 验证上传、识别结果入库、诊断、待复核及失败分支 |
| 构建与数据库 | 干净安装和前端构建通过。SQLite 与 PostgreSQL 17.11 均通过最新迁移及结构校验。实际启动生产配置的 PSA，完成教师改密、学生入班答题、讲义入库和引用。冷备份恢复后核对了账号、班级、作答及资料原件 |

本次更新的后端套件通过 102 项测试，实际应用通过 10 项 Chromium 浏览器测试，GitHub Pages 模拟演示通过 13 项 Chromium 浏览器测试。npm 官方审计和 51 个已安装 Python 包的 PyPI 公告复扫均未报告已知漏洞。

GitHub 上的基线通过了 PostgreSQL、Compose 和浏览器任务。本地独立 PostgreSQL 测试覆盖了本次更新。新版 Docker 镜像、`pg_dump` / `pg_restore` 逻辑恢复脚本以及企业的 HTTPS 入口仍需在目标环境复验。[基线自动检查](https://github.com/0731Shayne/PSA/actions/runs/44310193595)

## 本轮修复

- 统一截止时间的存取与比较，按服务器收到提交的时刻标记迟交。统一题号，并兼容历史小写记录。
- 防止快速切题或切换班级时把迟到的结果应用到当前页面。修复单选题选择和客观题确定性判分。教学包的编辑和导出遵循当前选中的版本。
- 在回复前校验班级作业的辅导权限，限制待作答题目的解答内容。提示和分步模式提供题干、知识点和允许的课程资料。
- 修复 RAGFlow 的数据集和文档范围，丢弃范围外引用，完整读取文档分页。DeepSeek 流式请求可随取消或超时关闭。
- 更新前端和 Python 的受影响依赖，修复 Compose 中数据库密码含特殊字符时的连接配置，排除配置、运行数据库和常见备份文件。新增 Compose 验收脚本覆盖教师初始化、改密和备份恢复。

## 正式上线前要完成的验收

| 事项 | 通过条件 |
| --- | --- |
| 目标环境生产部署 | 在企业环境使用新版 Compose 或企业容器配置，完成 PostgreSQL 迁移、HTTPS 访问、教师首登改密。把备份恢复到独立库并核对班级、作答、资料原件及账号 |
| 企业外部服务 | 用拟上线的 DeepSeek、MinerU、RAGFlow 账号和合成课程数据验证流式答疑、OCR、资料授权检索、超时、服务不可用及恢复。核对企业允许传输的数据范围 |
| 容量与故障 | 按企业的班级人数、课程资料量和同时在线人数确认指标，验收集中交作业、图片上传、OCR 和复核。当前复核列表一次包含最多 50 份作答及其图片，慢 OCR 或检索期间也可能占用数据库连接 |
| 访问控制与运行 | 验证企业入口的限流、监控告警、凭据管理、权限运营和日志留存，确认备份周期与恢复目标 |
| 教学内容 | 公开演示和源码分发包含题库答案，适用于练习、课堂诊断与形成性评价。需要保密的正式考试使用企业独立试卷。题库结构已核验，题目内容与答案准确性由课程负责人抽审 |

部署和日常验收步骤见 [企业交付验收清单](ACCEPTANCE.md) 与 [部署说明](../README.md)。
