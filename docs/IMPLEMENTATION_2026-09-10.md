## 核心问题逐项落实

| 原问题 | 已实现的行为 | 验证方式 |
|---|---|---|
| 分数结构被破坏，错误答案判对 | 保留大小写、括号、标点和数学结构；分数、十进制使用精确有理数比较。无法可靠判断时保存为待复核，并记录判分来源与版本 | 分数、上下标、集合、多选表达反例；接口验证 `1/940` 不再等于 `19/40` |
| 看解析后订正被视为独立迁移 | 记录全局解析曝光、提示和答疑辅助；只有首次未受辅助的新题作答可作为独立证据。换任务不会清除曝光；数据库约束避免并发产生两份首次独立记录 | 解析订正、题库提示、普通/流式答疑、跨任务与并发测试 |
| 待复核降低掌握度、制造风险 | 待复核保留提交与交付状态，排除于能力、错误类型与风险分组计算；教师可查看原始作答、参考答案并填写复核结论；学生回看时同步新反馈 | 学情、分组、复核权限、重复复核与浏览器流程验证 |
| 置信区间水平与临界值不一致 | 80%—99% 每档使用对应正态分位数；明确 N(0,1)、总体方差已知的实验假设 | 80、89、94、95、98、99 分位数与覆盖率回归 |
| 调参数图形几乎不变 | 正态分布固定坐标并叠加标准正态基准；贝叶斯图标出当前先验点；泊松图叠加精确二项分布；手机图表使用可读的刻度与比例 | 浏览器调整标准差，确认曲线变化而基准不动；纯计算检查 |
| 切题或刷新丢失作答 | 按用户、任务、题号保存答案、思路、图片和提交状态；刷新、切题可恢复；加载最新提交可回看；存储失败提示并保护离页 | 桌面/手机切题、刷新；图片数据与文件名恢复；教师复核反馈回看 |
| 实验历史无法重现 | 保存参数、随机种子与算法版本；重开恢复当时曲线；重新运行是独立操作；旧记录显示原摘要并说明不能精确重现 | 保存、重新运行、重开曲线一致；接口字段往返 |
| 超时重试重复保存、详情失败一直加载 | 文字诊断限制 25 秒，前端留出 45 秒；图片提交留出 210 秒；每份作答持久化提交编号，重复请求返回原记录，不重复计数；详情/历史加载失败提供明确重试入口 | 并发与顺序重复请求、编号冲突、原始历史数据、浏览器重复提交 |

## 页面与视觉调整

- 保留米白、深绿的课程风格，减少全页网格、装饰英文标签与重复说明。
- 教师首页以班级、待复核作答、进行中任务为中心；学生首页突出继续任务、截止时间和学习重点。
- 班级雷达分为知识点与分组、学生证据、任务与发布、待复核四个区域，支持查看学生证据摘要。
- 教学包提供可直接开始的课程范例，折叠更多课堂设置，减少初始空白，明确预览、编辑、发布流程。
- 手机作答压缩页头和截止说明，隐藏全局底栏，保留固定在可视区域的提示与提交操作。
- 学习路径补充待复核、不同题目数和规则估计口径；同一道题反复订正不再增加证据充足度。
- 实验室以图表为中心，历史参数显示中文名称，支持同种实验记录比较。
- 答疑新建/切换会话后自动收起手机设置面板；过期的历史请求不会覆盖新对话。

## 工程与兼容处理

- 实验模型、控件、图表已拆成独立模块，计算回归加入持续集成。
- 学习汇总部分指标改为数据库聚合；学情查询仅取统计所需字段，避免批量读取图片和长篇作答；历史作答支持分页，复核队列每批 50 条。
- React、路由和图标分开缓存。最大构建块从审查时约 779 kB 降至约 504 kB，仍保留构建体积提示，不以此宣称已完成移动网络性能压测。
- 新迁移：`20260910_0006`；既有本地 SQLite 支持增量补列。旧作答默认不追认为独立迁移，历史独立迁移人数可能下降，这是避免无法核实的旧证据继续计数。
